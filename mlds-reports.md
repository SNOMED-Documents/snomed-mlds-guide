# MLDS Reports

## Summary Report

For the moment this should be done daily and is a manual task.

MLDS reports are generated into the following Google sheet - 

<https://docs.google.com/spreadsheets/d/12myokMinYxBds0mQFUINbtm4V3u9f03zB9ckWXSwgDg/edit#gid=0>

These are generated by going to the staff interface, then Affiliate Management, then selecting to show 'All Affiliates', change the 'Standing' filter to be 'All' and then exporting as a csv by clicking on Export to CSV, and then pasting the contents into the **'All Data'** tab on the relevant Google sheet in the folder above. NOTE: do not to paste in the to Data tab as this is a calculated sheet. 

There are a number of other Google sheets in the same folder, one for each of the Members using MLDS. These reports are updated automatically once the new data is pasted as described above, so no need for any other action for Member's reports.

## Download Report

This report is generated off the database to indicate the number of times different files have been downloaded. This is only run on a weekly basis and the results are **added** to the existing results in the Google sheet as MLDS has a tendency to delete results if a release is removed from MLDS (as has happened). The SQL used to get the data is as follows:
[code] 
    SELECT DISTINCT to_char(event_date, 'YYYY-MM-DD') AS logDate, concat (affiliate_details.first_name, ' ', affiliate_details.last_name), organization_name, release_file.label, country.common_name, member.key
    FROM t_persistent_audit_event, affiliate, affiliate_details, country, release_file, member
    WHERE event_type = 'RELEASE_FILE_DOWNLOADED'
    AND t_persistent_audit_event.affiliate_id = affiliate.affiliate_id
    AND affiliate.affiliate_details_id = affiliate_details.affiliate_details_id
    AND t_persistent_audit_event.release_file_id = release_file.release_file_id
    AND affiliate_details.country_iso_code_2 = country.iso_code_2
    AND affiliate.home_member_id = member.member_id
    AND event_date > '2019-04-11'
    ORDER BY logdate
[/code]

The output is then pasted to the end of the data in the **All Downloads** tab in the Google sheet.

Once complete, please update the _**event_date**_ criteria in the above query to the date of the last record in the results so that the next time the query is run, the correct results are retrieved and there is no duplication.

## Overall Report For Finance

This is to be generated monthly at the end of the month 

Similarly generated from the following SQL,and then copied into the relevant report in Google. (updated 08 Apr 2021 )
[code] 
    SELECT commercial_usage.affiliate_id, commercial_usage.start_date, commercial_usage.end_date, affiliate.standing_state, affiliate.created, affiliate_details.agreement_type, affiliate_details.email, concat (affiliate_details.first_name, ' ', affiliate_details.last_name) AS applicant, concat (affiliate_details.type, '-', affiliate_details.subtype) AS type, affiliate_details.organization_name, affiliate_details.organization_type,country.common_name, current_usage, planned_usage, purpose, implementation_status, other_activities, commercial_usage_count.snomed_practices, commercial_usage_count.hospitals_staffing_practices, commercial_usage_count.databases_per_deployment,  commercial_usage_count.deployed_data_analysis_systems, COUNT(commercial_usage_entry.commercial_usage_id) AS hospitals, affiliate.notes_internal AS notes, "member"."key" AS "member", affiliate.notes_internal 
    FROM  affiliate, affiliate_details, member, country, commercial_usage_count, commercial_usage
    LEFT JOIN commercial_usage_entry ON commercial_usage.commercial_usage_id = commercial_usage_entry.commercial_usage_id 
    WHERE commercial_usage.affiliate_id = affiliate.affiliate_id
    AND affiliate.affiliate_details_id = affiliate_details.affiliate_details_id
    AND affiliate_details.country_iso_code_2 = country.iso_code_2
    AND commercial_usage.commercial_usage_id = commercial_usage_count.commercial_usage_id
    AND commercial_usage.state = 'SUBMITTED'
    AND affiliate.home_member_id = member.member_id
    AND affiliate_details.email NOT LIKE '%ihtsdo.org%'
    GROUP BY commercial_usage.affiliate_id, commercial_usage.start_date, commercial_usage.end_date, affiliate.standing_state, affiliate.created, affiliate_details.email, affiliate_details.first_name, affiliate_details.last_name, affiliate_details.organization_name, affiliate_details.organization_type, country.common_name, current_usage, planned_usage, purpose, implementation_status, other_activities,
    commercial_usage_count.snomed_practices, commercial_usage_count.hospitals_staffing_practices, commercial_usage_count.databases_per_deployment,  commercial_usage_count.deployed_data_analysis_systems, affiliate_details.agreement_type, affiliate.notes_internal, "member"."key", affiliate_details.type, affiliate_details.subtype
    ORDER BY commercial_usage.affiliate_id 
    
[/code]

## Affiliates Report for a Given Member Country

On request by a Member country looking for reports of all affiliates in their country, including those registered initially with another Member. The example given here is Germany.
[code] 
    /* report for all affiliates working in a given country code */
    SELECT commercial_usage.affiliate_id, commercial_usage_entry.country_iso_code_2, 
    commercial_usage_count.country_iso_code_2 as count_country,
    commercial_usage.start_date, commercial_usage.end_date, affiliate.standing_state, 
    affiliate.created, affiliate_details.agreement_type, 
    concat (affiliate_details.first_name, ' ', affiliate_details.last_name) AS applicant, 
    concat (affiliate_details.type, '-', affiliate_details.subtype) AS type, 
    affiliate_details.organization_name, affiliate_details.organization_type, 
    current_usage, planned_usage, purpose, implementation_status, other_activities, 
    commercial_usage_count.snomed_practices, commercial_usage_count.hospitals_staffing_practices, 
    commercial_usage_count.databases_per_deployment,  commercial_usage_count.deployed_data_analysis_systems, 
    COUNT(commercial_usage_entry.commercial_usage_id) AS hospitals, affiliate.notes_internal AS notes
    FROM  affiliate, affiliate_details, "member" m2, commercial_usage_count, commercial_usage
    LEFT JOIN commercial_usage_entry ON commercial_usage.commercial_usage_id = commercial_usage_entry.commercial_usage_id
    WHERE commercial_usage.affiliate_id = affiliate.affiliate_id
    and affiliate.home_member_id = m2.member_id 
    AND affiliate.affiliate_details_id = affiliate_details.affiliate_details_id
    AND commercial_usage.commercial_usage_id = commercial_usage_count.commercial_usage_id
    AND commercial_usage.state = 'SUBMITTED'
    and  (commercial_usage_entry.country_iso_code_2 = 'DE' or commercial_usage_count.country_iso_code_2 = 'DE')
    AND affiliate_details.email NOT LIKE '%ihtsdo.org%'
    GROUP BY commercial_usage.affiliate_id, commercial_usage_entry.country_iso_code_2, commercial_usage_count.country_iso_code_2,
    commercial_usage.start_date, commercial_usage.end_date, affiliate.standing_state, affiliate.created, affiliate_details.first_name, affiliate_details.last_name, affiliate_details.organization_name, affiliate_details.organization_type, current_usage, planned_usage, purpose, implementation_status, other_activities,
    commercial_usage_count.snomed_practices, commercial_usage_count.hospitals_staffing_practices, commercial_usage_count.databases_per_deployment,  commercial_usage_count.deployed_data_analysis_systems, affiliate_details.agreement_type, affiliate.notes_internal, affiliate_details.type, affiliate_details.subtype
    ORDER BY organization_name, commercial_usage.affiliate_id 
[/code]

  

## Members Download Report

This report is generated off the database to indicate the number of times files have been downloaded by Members through the member view. Currently this is just run on request but is not put anywhere.

The SQL used to get the data is as follows:
[code] 
    SELECT to_char(event_date, 'YYYY-MM-DD') AS logDate, principal, release_file.label
    FROM t_persistent_audit_event, release_file
    WHERE event_type = 'RELEASE_FILE_DOWNLOADED'
    AND affiliate_id IS NULL 
    AND principal <> 'member-test'
    AND principal <> 'MISSING PRINCIPAL'
    AND t_persistent_audit_event.release_file_id = release_file.release_file_id
[/code]

# NRC Staff Accounts
If you have not already been assigned an account to manage affiliates within the MLDS, please send an email to [techsupport@ihtsdo.org](mailto:techsupport@ihtsdo.org) providing your name, email address and related NRC name.

If you have, please go to the login page here - [https://mlds.ihtsdotools.org/#/login](https://mlds.ihtsdotools.org/#/login) - and enter in the same user name and password that you use to log in to Confluence.
